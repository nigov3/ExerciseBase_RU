# Hevy Library Builder RU

## Что делает версия

- Загружает исходный каталог из `hasaneyldrm/exercises-dataset`.
- Получает текущие шаблоны упражнений Hevy.
- Сохраняет английское исходное название для сверки дубликатов.
- Переводит названия через проверенный словарь и композиционные правила для сочетаний оборудования, положения тела, хвата и движения.
- Если название нельзя разобрать без догадок, ставит `NEEDS_REVIEW` и не включает его в импорт.
- Берёт русские инструкции из `instructions.ru` и `instruction_steps.ru` исходного датасета.
- Сохраняет GIF в `output/gifs`, использует уже скачанные файлы повторно.
- Создаёт CSV для проверки и HTML-галерею.

## Запуск

В PowerShell из папки проекта:

```powershell
python hevy_builder.py
```

Скрипт создаёт `output/hevy_import_review.csv` и `output/exercise_gallery.html`. Обычный запуск ничего не создаёт в Hevy.

## Как проверить результат

В CSV:
- `name_en` — оригинальное английское название;
- `name_ru` — предложенное русское название;
- `translation_status=DICT` — точное соответствие из словаря;
- `translation_status=RULE` — составное название, полученное по правилам;
- `translation_status=NEEDS_REVIEW` — название не переведено автоматически, нужна ручная проверка;
- `instructions_ru` и `instruction_steps_ru` — русские инструкции из датасета;
- `import=YES` — предварительный флаг для переведённой позиции, если она не является дубликатом.

Перед импортом проверь названия в CSV. Для сомнительных строк оставь `import=NO`. Можно исправить `name_ru` вручную и поставить `import=YES`.

## Тестовый импорт

Только после проверки CSV:

```powershell
python hevy_builder.py --apply --limit 10
```

Для полного импорта после успешного теста:

```powershell
python hevy_builder.py --apply
```

Скрипт запросит подтверждение `IMPORT`.

## API-ключ

Ключ задаётся в переменной окружения `HEVY_API_KEY` в текущем окне PowerShell. Не вставляй ключ в сам скрипт, CSV, README или переписку. Если ранее раскрытый ключ ещё не отозван, отзови его и создай новый.

## Ограничение Hevy API

Публичный API создания шаблона упражнения не предоставляет поля для прикрепления GIF и русских инструкций. GIF и инструкции сохраняются локально в галерее/CSV. В Hevy через API передаются название, тип упражнения, категория оборудования и основная группа мышц.

## Проверка

Скрипт проверен на синтаксис Python и на контрольных примерах составных названий. Полный прогон на твоём наборе данных и импорт в Hevy не выполнялись. Фактическое число автоматически переведённых упражнений появится в итоговой статистике после запуска на твоём компьютере.
